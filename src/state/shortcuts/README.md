# state/shortcuts

Pintasan papan ketik yang berlaku di mana saja dalam ruang, selama orang tidak sedang mengetik.

**Taruh di sini:** Pintasan global baru. Tambahkan juga ke `a11y/keys.ts` supaya muncul di lembar `?`.

**Bukan di sini:** Pintasan saat fokus di simpul (`a11y/useTreeKeyboard.ts`).

| File | Isi |
| --- | --- |
| useGlobalShortcuts.ts | Spasi, Ctrl+K/Z/M/B, angka, Escape, dan lainnya |
