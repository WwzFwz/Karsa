# layout

Kerangka ruang yang membungkus setiap halaman di dalamnya.

**Taruh di sini:** Bagian kerangka yang tampil di semua halaman ruang.

**Bukan di sini:** Pintasan global (`state/shortcuts/`), isi halaman (`app/pages/`).

| File | Isi |
| --- | --- |
| RoomShell.tsx | Merakit bilah atas, navigasi, halaman, dock, dan palet |
| TopBar.tsx | Nama ruang, lencana lokal, peserta, bagikan, bentuk |
| Sidebar.tsx | Navigasi kiri, bahasa, tema, kartu kode ruang |
