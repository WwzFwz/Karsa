# shared

Komponen dan data tampilan yang dipakai oleh dua fitur atau lebih.

**Taruh di sini:** Sesuatu yang dipakai di banyak tempat dan tidak tahu fitur mana yang memakainya.

**Bukan di sini:** Komponen milik satu fitur. Folder ini tidak boleh mengimpor folder komponen lain; skrip batas menolaknya.

| File | Isi |
| --- | --- |
| Dialog.tsx | Kerangka dialog yang aksesibel |
| ErrorBoundary.tsx | Penangkap galat render, supaya tidak ada layar putih |
| NodePicker.tsx | Pemilih simpul lewat daftar, bukan kursor (D6) |
| InlineTitle.tsx | Menyunting judul di tempat |
| LangSwitch.tsx | Sakelar ID/EN |
| ThemeSwitch.tsx | Sakelar tema terang/gelap (D36) |
| icons.tsx | Ikon SVG inline (D13) |
| labels.ts | Label tampilan: lencana tipe, warna tipe, petunjuk bentuk |
