# commands

Palet perintah Ctrl+K: setiap perintah, alat, templat, dan perpindahan dalam satu daftar yang bisa dicari (D56).

**Taruh di sini:** Perubahan pada palet atau cara entri disusun.

**Bukan di sini:** Perintah dokumen itu sendiri (`core/commands/`).

| File | Isi |
| --- | --- |
| CommandPalette.tsx | Dialog palet dan pencarian dua tingkat (D57) |
| entries.ts | Daftar entri, disusun dari registry; tanpa React |
| usePaletteRoom.ts | Menerjemahkan keadaan ruang untuk daftar entri |
